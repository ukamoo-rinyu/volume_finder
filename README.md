# 建築規制ボリューム検討（volume_finder）

QGISプラグイン。敷地条件から、道路斜線・隣地斜線・日影規制・容積率・建蔽率をすべて満たす延床面積が最大となるボリュームを自動探索する。

- 敷地選択 → 辺の一覧生成 → 道路幅員などの手入力
- 国土数値情報A29から用途地域を自動取得・面積按分
- 道路斜線・隣地斜線・容積率・建蔽率・日影規制（影が落ちる先の区域を含む、法56条の2第4項）を満たす、実務的な配置の自動探索（ver0.2.0）
  - 回転角は境界線に平行な向きだけに離散化（斜め配置を作らない）
  - 建物を敷地境界に「寄せる」アンカー配置（北・南・東・西・四隅・中央）
  - 容積消化率だけでなく、有効空地（残余地の最大内接矩形）・南面採光も加味した多目的スコアで順位付け。重みはスライダーで即座に並び替えられる（再探索不要）
  - 似た案（重心・延床面積が近い案）を間引いて多様な上位案を提示
- 結果をQGISレイヤ／JSON／HTMLで出力。HTML側にも、複数用途地域の内訳・影が落ちる先の区域の判定を参考カードとして表示する

既存のブラウザツール「日影図・高さ制限チェッカー」とJSON（`hikage-checker`形式）で連携する。探索結果はそのままHTMLツールで日影図・断面図を確認できる。

## インストール

QGIS の「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」で、リリースのZIPを指定する。

## 開発

`core/` はQGISに依存しない純粋なPython/numpyで書かれており、`test/` の単体テストはQGIS環境なしで実行できる。

```bash
pip install pytest
pytest test/
```

`ui/` `io/` はQGIS APIに依存する。

## 既知の限界

- 建物は単純な直方体1棟のみ（L型・コの字型・分棟などの配置類型別探索、パレート最適解の散布図UIは volume-study-search-spec.md ver0.2.0 の§5・§7として構想はあるが未実装）
- 二以上の前面道路の緩和（令132条）、天空率による適用除外は未対応
- 高度地区・地区計画・風致地区は未対応
- 地盤面の設定、敷地と道路の高低差は未対応
- 国土数値情報の境界精度は数m程度（按分値は参考値）
