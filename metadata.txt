about=EN: An initial-stage volume-study tool for consolidating/combining public facilities in Osaka City. Workflow: select a site -> automatically fetch and area-prorate the use-zone designation from Japan's National Land Numerical Information (A29) -> automatically search realistic building placements that satisfy road slant limits, neighboring-lot slant limits, floor-area ratio, building coverage ratio, and daylight/shadow regulations (including regulations triggered when the shadow falls on a neighboring regulated zone) -> export the results as a QGIS layer, JSON, and HTML. Version 0.2.0 upgrades the search from "maximize floor area only" to a practical multi-objective placement search: rotation angles are discretized to the site's own boundary directions, buildings are anchored against the site boundary instead of floating in the middle, and candidates are ranked by a combined score (floor-area ratio, usable open space, south-facing daylight) with near-duplicate results pruned. The HTML output now also shows a breakdown across multiple use zones and which shadow-regulation zone applies. It connects to the existing browser tool "日影図・高さ制限チェッカー" (Shadow Diagram / Height Limit Checker) via JSON (hikage-checker format), so a search result can be opened directly in that tool to check shadow diagrams and sections. Version 0.3.0 adds an experimental two-building placement search (detached wings, or an L-shaped massing when the gap is set to zero) that reuses the same slant/shadow logic as the single-building search, plus optional "facility type" presets (office, sports facility, nursery) that constrain floor height, floor-count range, footprint proportions and minimum footprint size, and (for nurseries) require a contiguous adjacent open yard -- so results look like real public-facility programs instead of just the tallest/thinnest box that maximizes floor area. It also fixes the anchor candidate pool being crowded out by a single dominant (near-maximum-footprint) candidate, so weaker anchor placements are no longer silently dropped before scoring. Published as an experimental release. / JA: 大阪市の公共施設における複合化・集約化の初期ボリュームスタディ用ツール。敷地選択→用途地域の自動取得・按分（国土数値情報A29）→道路斜線・隣地斜線・容積率・建蔽率・日影規制（影が落ちる先の区域を含む）を満たす実務的な配置の自動探索→結果をレイヤ／JSON／HTMLで出力、までを行う。ver0.2.0で探索を「容積最大化のみ」から「回転角の離散化・アンカー配置・有効空地や南面採光を含む多目的スコア・類似解の間引き」による実務的な配置探索に改良し、HTML出力側にも複数用途地域の内訳や影が落ちる先の区域の判定を表示するようにした。既存のブラウザツール「日影図・高さ制限チェッカー」とJSON（hikage-checker形式）で連携し、探索結果はそのままHTMLツールで日影図・断面図を確認できる。ver0.3.0では、単棟探索と同じ斜線・日影ロジックを使う実験的な2棟配置探索（分棟、離隔距離を0にするとL型）と、任意で選べる「施設タイプ」プリセット（庁舎・スポーツ施設・保育所）を追加した。施設タイプを指定すると階高・階数の範囲・プロポーション・最低建築面積・（保育所は）隣接空地の必須条件で候補を絞り込み、床面積最大化だけでは出てこない、実際の公共施設プログラムに近い案が出やすくなる。あわせて、候補プールが最大サイズに近い1件の候補に占有され、他のアンカーの候補が採点前に弾かれてしまう不具合も修正した。テスト版（experimental）として公開。Version 0.4.0 adds placement constraints to the HTML tool: a building can now only be created, moved, resized, and rotated within the site boundary, and instead of freezing when it hits the edge it slides smoothly along the boundary. It also adds a check for Osaka City's "terminal shadow" (終日日影) administrative guidance under the large-scale building pre-consultation system, distinct from the statutory shadow regulation (Building Standards Act Art. 56-2), shown in the shadow-diagram tab with its own map overlay. Also fixes a display bug where the statutory shadow-regulation violation overlay stayed drawn on the map even when that regulation did not apply to the current use zone, and a floating-point rounding bug in the new terminal-shadow check that could misclassify a genuinely non-compliant (fully shadowed all day) point as compliant. / ver0.4.0では、HTMLツールに建物の配置・移動の制限を追加した。建物は敷地の中でのみ生成でき、ドラッグ・大きさ変更・回転も敷地内にとどまるようになり、境界に当たったときも急に止まらず境界に沿って滑らかに動く。また、法56条の2の日影規制とは別の、大阪市の大規模建築物事前協議制度による「終日日影」の行政指導のチェックを日影図タブに追加した（専用の地図表示つき）。あわせて、日影規制が対象区域外のときも超過範囲の色表示が地図に残ってしまう表示不具合と、終日日影の判定で浮動小数の丸め誤差により本来超過となるべき地点を適合と誤判定する不具合を修正した。
